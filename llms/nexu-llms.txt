# Nexu

> Nexu is a Mexico City fintech that provides automotive financing at the point of sale.
> Founded in 2014 by Abdon Nacif and Fernando Gomez Arriola, it operates a digital lending
> platform used by Mexican car dealerships to originate auto credit and leasing offers in
> real time. Nexu publishes NO public API, developer portal, SDK, or machine-readable
> contract of any kind.

## About this file

This llms.txt was GENERATED by API Evangelist from the public Nexu web surface on
2026-08-26. It is not published by Nexu. Nexu does not serve an llms.txt of its own:
https://www.nexu.mx/llms.txt returns the site's Angular app shell (HTTP 200, text/html),
not a document.

## Products

- Credito automotriz - auto loan originated at the dealership, decisioned digitally.
- Arrendamiento - vehicle lease with a purchase option and no residual value.
- Distribution: dealer networks for 10+ OEM brands including Nissan, Volkswagen, Kia,
  Hyundai, Mazda, Honda, Ford, Chevrolet, BMW and Audi.

## API surface

None published. As of 2026-08-26 API Evangelist probed every Nexu host for a
machine-readable contract and found nothing:

- No OpenAPI/Swagger: /openapi.json, /openapi.yaml, /swagger.json, /v1/openapi.json,
  /api-docs, /redoc, /rapidoc, /v2/api-docs, /api/openapi.json, /api/swagger.json and
  /swagger/v1/swagger.json all miss on www.nexu.mx, landing.nexu.mx and team.nexu.mx.
- No GraphQL: /graphql returns the app shell, not a GraphQL endpoint.
- No MCP server, no A2A agent card, no AsyncAPI, no .proto, no WSDL.
- No /.well-known/ document of any kind on any host.
- No developer portal, no API reference, no public SDK on npm, PyPI, RubyGems or Maven.
  (The npm scopes @nexu-ai, @nexu-design and the PyPI package "nexu" belong to unrelated
  companies and must not be attributed to this Nexu.)
- The customer application at www.nexu.mx is an Angular SPA whose bundled environment
  declares `api: {url: ""}` - a same-origin, undocumented, private backend.
- landing.nexu.mx serves a WordPress core REST API at /wp-json/. That is the CMS behind
  the marketing site, not a Nexu product API, and is recorded here only so a reader knows
  it was seen and deliberately not catalogued as a Nexu API.
